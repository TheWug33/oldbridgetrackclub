# Old Bridge Track Club

React + Vite website for Old Bridge Track Club youth programs.

## Local Development

```bash
npm install
npm run dev
```

Site runs at `http://localhost:5173`.

## Build for Production

```bash
npm run build
```

Built files go to `/dist`.

## Deploy to Vercel

1. Push to GitHub
2. Go to vercel.com → Add New Project → Import repo
3. Framework: **Other**
4. Deploy

Any push to `main` auto-deploys.

## Structure

- `/src/components` — Individual page sections
- `/src/images.js` — Image data URIs
- `/src/index.css` — Global styles
